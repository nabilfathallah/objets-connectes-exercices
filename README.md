# Site web d’exercices : objets connectés et non connectés

Ce projet est un site éducatif pour les élèves de 9e année en informatique.

## Objectif
Apprendre à distinguer :
- les objets connectés
- les objets non connectés
- les avantages et limites de chaque catégorie

## Fichiers principaux
- `index.html` : structure du site
- `style.css` : design et mise en page
- `script.js` : interactions et quiz

## Comment ouvrir le site
Ouvrez simplement le fichier `index.html` dans un navigateur.

## Contenu pédagogique inclus
- définition des objets connectés
- définition des objets non connectés
- tableau de comparaison
- exercices interactifs
- quiz de validation
- correction

## Exemple de thème
"Objets connectés et non connectés"
